Set up form automation

  1. Deploy the web folder using GitHub Pages.
  2. On a computer, open Chrome or Edge and load the included extension folder as an unpacked extension.
  3. Open a supported job application page, click the extension, save your profile, then choose Fill form or Fill & submit.

The extension only acts on the active page after you invoke it. It does not bypass access controls, CAPTCHA, or sign-in, and cannot guarantee compatibility with every job portal. Chrome on Android does not support normal desktop extensions; the web app itself works on Android.
